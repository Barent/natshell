Keyboard shortcuts:
  Enter          — Send message
  Ctrl+C         — Copy selected text / cancel current operation
  Ctrl+E         — Copy entire chat to clipboard
  Ctrl+L         — Clear screen
  Ctrl+P         — Open model switcher (command palette)
  Ctrl+Y         — Copy Textual selection to clipboard
  Ctrl+Shift+C   — Copy entire chat
  Ctrl+Shift+V   — Paste from clipboard
  Shift+drag     — Select text in terminal
  Up/Down arrows — Navigate input history
  Click 📋       — Copy individual message
